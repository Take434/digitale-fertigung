This documents how I modeled a prototype of my final project in fusion. First I had to model the Flipdot Display which I will be using, after that I created the Frame.

More detailed Descriptions of the modeling process will be added in the future.
 ![[1.png]]created a sketch, center rectangle with dimensions according to the actual physical flipdot display.
![[2.png]]extrude the sketch, added appearance
![[3.png]]created a new sketch. rectangles according to the connectors and circuit on the physical display
![[4.png]]extruded the sketch for the left connector
![[5.png]]created a new sketch, made rectangles according to the physical connector
![[6.png]]extruded sketch to create shell of the connector
![[7.png]]

modeled one pin, by extruding a circle and applying chamfer
![[8.png]]used rectangular pattern tool to copy the pin and create the complete connector
![[9.png]]mirrored the connector shell
![[10.png]]mirrored the pins
![[11.png]]extruded the other rectangle to resemble the chip on the display
![[12.png]]to model the single flip dots, started with a sketch, created a rectangle and circles for the pins, created another rectangle, chamfered the corners and used move to turn 45 degrees
![[13.png]]

extruded the pins connecting the single flip dot to the base plate
![[14.png]]extruded the connecting plate, using an offset
![[15.png]]created another sketch, drew circles for more pins and something to resemble the wire wrapped around them
![[16.png]]extruded the inner circle to create the pins
![[17.png]]extruded the outer circle with an offset to mimic the copper wrapped around the pins
![[18.png]]

extruded the inner circle into the negative to resemble the connection in the physical
![[19.png]]

extruded the rectangle with an offset to create the base holding the flip dot
![[20.png]]

filled in the holes using extrude tool
![[21.png]]created a sketch for the flipdot,
![[22.png]] 

extruded the outer triangles connecting the flip dot to the base
![[23.png]]

extruded the circles to mimic the physical dot, these create the electromagnet to flip the dot
![[24.png]]

extruded the circle, save for the cutout, this is the flipping dot. Started adding appearances
![[25.png]]created a new sketch, made a line, this is the axis the dot is on
![[26.png]]tilted the dot along the axis by 5 degrees to mimic the physical dot
![[27.png]]created sketch, rectangle is the axis connecting the dot and base 
![[28.png]]created the axis by using the sweep tool and choosing the rectangle and axis created above
![[29.png]]
multiple combine steps have not been mentioned, used the rectangular pattern tool to copy the one dot along two axis creating the full display
![[30.png]]created a sketch for the frame, using a center rectangle, created two slots to hang the frame. These are made with the center to center slot tool and a line to be able to extrude the slots
![[31.png]]extruded the frame in both directions
![[32.png]]created another sketch, made two rectangles and a text to engrave
![[34.png]]extruded the two rectangles as a cover using an offset, extruded the rectangle on the backside at an offset
![[35.png]]extruded the text using an offset and the cut operation to "engrave" it into the cover
